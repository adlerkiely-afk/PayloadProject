# Bottom-deploy revision: CAD exports

Exported from Onshape on 2026-11-14. This revision is still being evaluated. I've printed a PLA+
prototype and run it on the servo, but it hasn't been load tested or through team review.

| File | Contents |
| --- | --- |
| `bottom-deploy-assembly.step` | Full assembly, stowed position |
| `print-parts/frame.3mf` | Frame: base, servo deck, corner walls and bridge posts |
| `print-parts/carriage.3mf` | Carriage that holds the probes and rides on the guide rods |
| `print-parts/bridge.3mf` | Bridge that holds the tops of the guide rods |
| `print-parts/crank.3mf` | Crank, bolted to the servo horn |
| `print-parts/link.3mf` | Link between crank and carriage |
| `print-parts/horn.3mf` | Servo horn, reference geometry only |
| `print-parts/servo.3mf` | Servo envelope, reference geometry only |
| `print-parts/hardware.3mf` | Pins, guide rods and probes, reference geometry only |

The servo is a placeholder block for now. Its mounting tabs and screw holes aren't modeled yet.
